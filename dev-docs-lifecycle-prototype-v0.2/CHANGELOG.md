# Changelog

## v0.2.0 — prototype prerelease — 2026-11-13

- Default project development artifacts to `docs/` regardless of repository size; established explicit project policy may override.
- Keep standard root entrypoints and local module READMEs in place; add a lightweight `docs/README.md` index for new development docs.
- Add root-placement regression checks and behavioral scenario T11; separate project-root clutter from authoritative policy.
- Move prototype review notes into `docs/` and update README links.
- Add default-on Skill enablement with explicit task-level on/off choices.
- Add an optional Pi extension with `/dev-docs on`, `/dev-docs off`, and `/dev-docs status`, persistent project mode, and automatic instruction loading.
- Add eight Pi extension-handler tests and a mode-control guide. Interactive TUI verification and automated semantic Agent evaluations remain pending.
- Include an explicitly labeled implementation validation sample and its documentation index entry.

## v0.1.0 — initial prototype

- Initial standalone development-doc lifecycle Skill.
- Incremental and maintenance modes, lifecycle classification and archive safeguards.
- Deterministic fixture checker for local relative paths, file hashes and snapshots.
- Explicit separation between executable checks and unrun semantic Agent cases.

The v0.1.0 entry describes the initial local prototype; it was not published as a release.
